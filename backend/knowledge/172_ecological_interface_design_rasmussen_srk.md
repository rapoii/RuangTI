# Module 172: Ecological Interface Design & Rasmussen's SRK Framework

## 1. Cognitive Systems Engineering
Ecological Interface Design (EID) maps work domain constraints directly onto perceptual representations, supporting all three levels of Rasmussen’s SRK taxonomy without forcing unnecessary cognitive processing.

## 2. Rasmussen’s SRK Framework
*   **Skill-Based:** Automated sensorimotor patterns; no conscious attention. Interface: Physical affordances, direct manipulation.
*   **Rule-Based:** Stored if-then rules; sign-based processing. Interface: Signs, indicators, procedural cues.
*   **Knowledge-Based:** Novel problem solving; symbolic reasoning. Interface: Functional relationships, causal diagrams, Abstraction Hierarchy.

## 3. Abstraction Hierarchy (AH)
Five-level representation of work domain:
1.  Physical Form
2.  Physical Function
3.  Generalized Function
4.  Abstract Function
5.  Functional Purpose

$$
Information_{display} \supseteq Constraints_{work\_domain}
$$

## 4. EID Design Principles
*   Represent part-whole hierarchy spatially.
*   Map functional relationships to geometric constraints.
*   Use emergent features for system state visualization.

Recent 2023 application to Flexible Manufacturing Systems demonstrated 40% reduction in diagnosis time for novel faults (Sage Journals, 2023).
