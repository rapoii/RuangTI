# Modul 418: Penerapan Kebijakan Strategis (Hoshin Kanri), Matriks Penyelarasan X-Matrix, Proses Catchball, dan Format Standar A3 Problem Solving Toyota

## 1. Domain Profesi & Ruang Lingkup
Profesi **Operational Excellence Leader / Strategic Deployment Specialist & Master Black Belt** bertugas menyelaraskan visi jangka panjang direksi (*True North*) dengan proyek perbaikan harian di lantai kerja (*Gemba*), memfasilitasi negosiasi target lintas level (*Catchball Process*), serta memimpin penyelesaian masalah kritis dengan format 1-halaman A3.

---

## 2. Kerangka Kerja Hoshin Kanri & Matriks X (Hoshin Kanri X-Matrix)

X-Matrix memetakan keselarasan 4 dimensi strategis dalam satu lembar kerja koordinat:

```
                          [ATAS: Target Tahunan (Annual Objectives)]
                                           ^
                                           | (Hubungan Kuat ● / Sedang ⨀)
 [KIRI: Sasaran Strategis 3-5 Tahun] <----+----> [KANAN: Indikator Metrik (KPIs / Targets)]
                                           | (Hubungan Kuat ● / Sedang ⨀)
                                           v
                        [BAWAH: Inisiatif Prioritas (Top Improvement Projects)]
                                           |
                                  [Pemberian Tanggung Jawab Tim (RACI Matrix)]
```

### Hubungan Matriks 4-Arah:
1. **Kuadran Kiri (Strategic Objectives / Breakthrough Goals)**: Sasaran terobosan 3–5 tahun (e.g., *"Menurunkan biaya mutu sebesar 40%, menjadi pabrik net-zero emission"*).
2. **Kuadran Atas (Annual Objectives)**: Turunan target tahun berjalan (e.g., *"Reduksi OEE loss 15%, zero scrap di lini machining"*).
3. **Kuadran Kanan (Targets / Metrics / KPIs)**: Ukuran kuantitatif keberhasilan (e.g., *OEE $\ge 88\%$, LTIR $= 0$, Scrap $< 50	ext{ ppm}$*).
4. **Kuadran Bawah (Top Improvement Initiatives / Projects)**: Proyek perbaikan Lean Six Sigma yang dieksekusi (e.g., *Proyek SMED Lini 2, Implementasi Poka-Yoke Sensor, Audit Energi ISO 50002*).

---

## 3. Proses Catchball (Negosiasi Target Dua-Arah)

Penerapan strategi bukan instruksi sepihak dari atas ke bawah (*Top-Down Dictation*), melainkan proses lempar-tangkap bola (*Catchball*):
- **Manajemen Puncak**: Melemparkan sasaran strategis ("Apa yang harus dicapai").
- **Manajemen Menengah & Supervisor**: Mengkaji kelayakan sumber daya, memberikan umpan balik, dan mengajukan inisiatif taktis ("Bagaimana cara mencapainya").
- **Konsensus**: Menghasilkan target yang realistis, disepakati bersama, dan memiliki kepemilikan penuh (*ownership*).

## 4. Format Standar A3 Problem Solving Toyota (Toyota 8-Step Practical Problem Solving)

Laporan A3 merangkum investigasi masalah teknis ke dalam selembar kertas ukuran A3 ($297 	imes 420	ext{ mm}$):

```
+------------------------------------------+------------------------------------------+
| 1. BACKGROUND & PROBLEM CLARIFICATION   | 5. COUNTERMEASURES (SMART ACTION PLAN)   |
|    - Latar belakang bisnis & True North  |    - Tindakan pencegahan akar penyebab   |
|    - Gejala masalah aktual di Gemba      |    - PIC, Timeline, Budget               |
+------------------------------------------+------------------------------------------+
| 2. CURRENT STATE (5W2H & DATA TREN)     | 6. IMPLEMENTATION & PROGRESS TRACKING    |
|    - Peta proses aktual / VSM            |    - Gantt chart eksekusi tindakan       |
|    - Kuatifikasi gap (Target vs Aktual)  |    - Status pencapaian per milestone     |
+------------------------------------------+------------------------------------------+
| 3. TARGET SETTING (SMART GOAL)           | 7. RESULTS CONFIRMATION & KPI EVALUATION |
|    - Target numerik yang terukur         |    - Grafik perbandingan Before vs After |
|    - Batas waktu penyelesaian            |    - ROI & Penghematan Biaya Finansial   |
+------------------------------------------+------------------------------------------+
| 4. ROOT CAUSE ANALYSIS (5-WHY & 6M)      | 8. STANDARDIZATION & SHARING (YOKOTEN)   |
|    - Fishbone diagram / Is-Is Not Matrix |    - Update SOP, Control Plan, WI        |
|    - 5-Why verifikasi logis sampai akar  |    - Deployment horizontal lini serupa   |
+------------------------------------------+------------------------------------------+
```
